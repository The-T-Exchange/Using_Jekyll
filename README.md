Norman's presentation on the use and abuse of Jekyll for Websites hosted anywhere, but specifically on GitHub.

The files in this directory are the LaTeX source files, `*.tex` for Norman's instructions. You can download a PDF of the instructions from the "releases" page.

These instructions are helpful to anyone who may be permitted to update the T-Exchange website.
